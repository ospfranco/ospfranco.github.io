Oscar Franco

Freelance Software Engineer

I like pushing the boundaries of technology. I was among the first developers writing JSI modules for React Native, worked in deeply technical projects like porting Nodes Crypto into react-native-quick-crypto, then porting aws-lc-rs to RN, made Prismas Rust engine work on React Native and since then I've maintained several open source projects and led engineering teams — though I still enjoy digging into novel, under-documented techniques: dynamic linking on iOS, hacking the Mapbox SDK to render custom tile sets, storing SSH keys on a YubiKey. You'll find some of that writing below.

Currently based in South America, nowadays spending most of my time on Rust these days, particularly around verifiable computing with Intel SGX. Won the German Design Award 2025 with Sol. Send me an e-mail if you are interested in contract work.
